# 单次运行记录

## 环境
- 系统 / 版本 / 实际模型 / 推理强度：
- 普通模式还是 Plan 模式：
- 可用工具、权限、扩展、额外用户或项目指令：
- 开始 / 结束时间；是否达到统一时间预算：
- 人工干预（含权限批准、需求澄清；记录原文）：

## Stage A
- 是否显示显式计划？内容及记录位置：
- 哪次行动选择最值得研究？工具、参数及记录位置：
- 哪次真实反馈改变了后续行动？失败 → 修改 → 重测：
- 如果没发生上述行为，写“未观察到”，不要推断不支持。
- Agent 最后的完成声明：
- 声明前实际运行了哪些检查：
- 独立验收结果 / report 路径：
- 是否修改了任务说明、样例数据或原有测试？原因：
- 结束原因：完成声明 / 主动放弃 / 预算终止 / 环境错误 / 人工中断。

## 可选 Stage B（收到新要求之后）
- Stage A 结果是否已先保存：
- 是否继续同一会话：
- 是否修改原计划或建立新计划：
- 是否保持原有行为并重测：
- 完成声明 / 独立验收结果：

## Token 和观测限制
- 运行 agent 自身的 input / output / cache / reasoning token；来源及覆盖范围：
- UI/导出中缺失或截断的内容：
- 是否包括子 agent、重试、压缩：
- 这些数据与任务内被分析的“样例日志 token”不是同一个量。

## 一句话观察
只描述本次行为；不把单次结果推广为系统整体能力。
